# Windows32 C++ Exploration

A collection of experiments, notes, and small projects created while learning the Win32 API and native Windows development in C++.

This repository serves as both a learning journal and a reference for Windows programming concepts, documenting discoveries, code examples, and lessons learned along the way.

## Goals

* Learn how native Windows applications interact with the operating system
* Understand the fundamentals of the Win32 API
* Explore Windows-specific data types, structures, and functions
* Build practical examples to reinforce concepts
* Create a personal reference for future projects

## Why This Repository Exists

Many Win32 tutorials focus on getting code working without explaining what is happening underneath.

This repository takes a different approach:

* Experiment first
* Read the documentation
* Break down the concepts
* Document observations
* Build understanding through practice

The goal is not just to learn how to call an API, but to understand why it works and how it fits into the Windows operating system.
